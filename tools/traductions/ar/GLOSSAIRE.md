# Version arabe de fatichanelya.com — règles de traduction

Référence partagée par tous les fichiers de `tools/traductions/ar/`. Le français du site est la
source ; l'arabe en est la traduction fidèle, jamais une réécriture.

## Registre
- **Arabe standard moderne** (fus'ha), clair, chaleureux, sans emphase. Phrases courtes.
- Le site s'adresse au lecteur au **singulier**, forme de politesse neutre de l'arabe moderne
  (masculin singulier par convention des interfaces : « أضف », « اكتشف », « يمكنك »). Pas de pluriel
  de politesse « أنتم », pas de féminin systématique. Exception : quand le français est
  explicitement féminin pour désigner Fati elle-même.
- Fati parle à la première personne là où le français le fait (« je réponds moi-même » →
  « أجيب بنفسي »).
- **Aucune allégation santé**, jamais : pas de « يعالج », « يشفي », « يقوّي المناعة », « يخفض »,
  « مفيد لـ », « يساعد على » appliqué à la santé. On traduit ce que le français dit, et le
  français ne promet rien. Si une phrase française paraît ambiguë, la traduire au plus près
  sans l'améliorer.
- Rien n'est ajouté, rien n'est retiré : mêmes phrases, mêmes réserves (« Liste complète sur
  l'emballage », « demandez l'avis d'un professionnel de santé »).

## Noms propres et marques (restent en caractères latins)
Fatichanelya, DXN, Naturixa, Velix Digital, WhatsApp (→ واتساب en texte courant, WhatsApp dans
les libellés de boutons reste acceptable), TikTok (→ تيك توك), Instagram (→ إنستغرام), Facebook
(→ فيسبوك), Google (→ غوغل), Meta (→ Meta), Kallow, Ganozhi, Zhicare, Morinzhi, Reishilium,
Ganocelium, codes RG / GL / SPF 50+, noms latins des espèces (Ganoderma lucidum, Hericium
erinaceus, Cordyceps sinensis, Morinda citrifolia, Hibiscus sabdariffa, Spirulina platensis,
Melaleuca alternifolia…) restent en latin, précédés de leur nom arabe : « فطر الغانوديرما
(Ganoderma lucidum) ».

## Noms de produits
Titre arabe = descripteur arabe + nom propre translittéré + « DXN » en latin à la fin.
Exemples : « قهوة لينجزي السوداء DXN », « صابون غانوزي DXN », « شامبو غانوزي DXN »,
« كبسولات ريشي غانو RG 90 DXN », « مورينزي DXN 285 مل », « جل استحمام كالو DXN ».
Le nom latin complet du catalogue apparaît **une fois** dans l'accroche ou la première phrase de
la description, entre parenthèses : « (DXN Lingzhi Black Coffee) ».

## Chiffres, unités, ponctuation
- Chiffres **occidentaux** (0-9), jamais indo-arabes. Décimale avec virgule comme en français :
  « 4,5 غ », « 26,40 € ». Le « × » se garde : « 20 كيساً × 4,5 غ ».
- Unités : g → غ, mg → ملغ, ml → مل, l → ل, gélule(s) → كبسولة / كبسولات, comprimé → قرص,
  sachet(s) → كيس / أكياس, tube → أنبوب, flacon → عبوة, pot → علبة, boîte → علبة, %
  reste « % ».
- Ponctuation arabe : virgule « ، », point-virgule « ؛ », point d'interrogation « ؟ ». Les
  guillemets « » se gardent. Les deux-points « : » se gardent.
- Dates et prix ne changent pas de format.

## Formats de fichiers
- JSON : UTF-8, clés = slug français, retours à la ligne encodés « \n » exactement comme dans
  la source (une étape de mode d'emploi par ligne, un point clé par ligne).
- Markdown réduit des formations : paragraphes, « ## Titre », listes « - », **gras** —
  même structure que la source, ligne pour ligne.
- Pages légales : même HTML que la source (mêmes balises, mêmes attributs, même ordre), seuls
  les textes changent ; les marqueurs « [[À FOURNIR : …]] » restent **en français, tels quels**.
